Integrasi Perangkat ESP32 + RFID RC522

Website ini menyediakan 2 metode integrasi perangkat keras RFID secara resmi.

Metode A: Import Excel / CSV

Perangkat ESP32 atau komputer perantara menyimpan log scan ke file .xlsx atau .csv, lalu operator mengunggahnya melalui menu Import Excel.

Metode B: Wi-Fi HTTP POST (Server Perantara Aktif)

ESP32 mengirim JSON via Wi-Fi ke endpoint API server perantara Node.js, lalu browser otomatis mengambil dan mencatat absensi ke LocalStorage:

POST 
{
  "uid": "A1B2C3D4",
  "tanggal": "2026-11-13",
  "waktu": "06:55:00"
}
Uji Endpoint API (Simulasi HTTP POST dari ESP32)
